PIXEL CALCULATOR -> EXE

1. Install Node.js (LTS) from https://nodejs.org  (one time only)
2. Copy your background.mp3 into the "audio" folder
3. Double-click build.bat  (needs internet the first time)
4. Your app appears in the "dist" folder as "Pixel Calculator.exe"

To just test without building: open a terminal here and run
   npm install
   npm start

# ♡ Kuromi Themed Calculator

A cute, Kuromi-inspired calculator built with HTML, CSS, and JavaScript, featuring a pastel aesthetic, custom interface, sound effects, and music.

Available as both a **web calculator** and a **Windows desktop application**.

## ✧ Preview

**Web Version:**  
[Open Kuromi Calculator](https://voltivy.github.io/kuromi-calculator/)

**Desktop Version:**  
Download the Windows application from the [Releases](https://github.com/voltivy/kuromi-calculator/releases) page.

## ✧ Features

- Basic calculator operations
- Custom Kuromi-inspired interface
- Pastel-themed visual design
- Interactive buttons and animations
- Custom button sound effects
- Background music
- Dedicated desktop application
- Lightweight and easy-to-use interface

## ✧ Technologies Used

| Technology | Purpose |
|---|---|
| HTML | Application structure |

| JavaScript | Calculator functionality |

## ✧ Running Locally

### Web Version
1. Clone this repository.
2. Open the root `index.html` file in your browser.

### Desktop Version
1. Navigate to the `desktop` folder.
2. Install dependencies using:

```bash
npm install
```

3. Start the application using:

```bash
npm start
```
